 ## Submission Checklist
 
 ### Before Submission
 
 - [ ] Register for Apple Developer Program ($99/year)
 - [ ] Create App Store Connect record
 - [ ] Generate App Store icon (1024×1024, no transparency)
 - [ ] Capture all required screenshots
 - [ ] Create demo account for App Review
 - [ ] Test app thoroughly on real devices
 - [ ] Ensure all links work (Privacy Policy, Terms, Support)
 - [ ] Remove all debug code and console logs
 - [ ] Test push notifications
 - [ ] Verify in-app purchases (if any)
 
 ### Xcode Build Steps
 
 1. **Pull latest code from GitHub**
    ```bash
    git pull origin main
    ```
 
 2. **Install dependencies**
    ```bash
    npm install
    ```
 
 3. **Build the web app**
    ```bash
    npm run build
    ```
 
 4. **Add iOS platform (if not done)**
    ```bash
    npx cap add ios
    ```
 
 5. **Sync Capacitor**
    ```bash
    npx cap sync ios
    ```
 
 6. **Open in Xcode**
    ```bash
    npx cap open ios
    ```
 
 7. **In Xcode:**
    - Select your Apple Developer Team
    - Update Bundle Identifier if needed
    - Set Version to 1.0.0
    - Set Build to 1
    - Add App Icons to Assets.xcassets
    - Update Info.plist with privacy descriptions
    - Select "Any iOS Device" as build target
    - Product → Archive
    - Distribute App → App Store Connect
 
 ### After Submission
 
 - [ ] Monitor App Store Connect for review status
 - [ ] Respond promptly to any reviewer questions
 - [ ] Prepare marketing materials
 - [ ] Plan launch announcement
