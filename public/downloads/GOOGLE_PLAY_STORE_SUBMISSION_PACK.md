 ## Submission Checklist
 
 ### Before Submission
 
 - [ ] Register for Google Play Developer Account ($25 one-time fee)
 - [ ] Create app in Google Play Console
 - [ ] Complete Data Safety questionnaire
 - [ ] Complete Content Rating questionnaire
 - [ ] Generate Play Store icon (512×512)
 - [ ] Create Feature Graphic (1024×500)
 - [ ] Capture phone screenshots (min 2, max 8)
 - [ ] Test app on multiple Android devices
 - [ ] Ensure all links work (Privacy Policy, Terms)
 - [ ] Remove debug code and verbose logging
 - [ ] Test push notifications on Android
 - [ ] Verify in-app purchases (if any)
 
 ### Build Steps
 
 1. **Pull latest code from GitHub**
    ```bash
    git pull origin main
    ```
 
 2. **Install dependencies**
    ```bash
    npm install
    ```
 
 3. **Build the web app**
    ```bash
    npm run build
    ```
 
 4. **Add Android platform (if not done)**
    ```bash
    npx cap add android
    ```
 
 5. **Sync Capacitor**
    ```bash
    npx cap sync android
    ```
 
 6. **Open in Android Studio**
    ```bash
    npx cap open android
    ```
 
 7. **In Android Studio:**
    - Update `build.gradle` with correct versionCode and versionName
    - Add app icons to `res/mipmap-*` folders
    - Verify permissions in AndroidManifest.xml
    - Build → Generate Signed Bundle / APK
    - Select "Android App Bundle" (recommended for Play Store)
    - Sign with your upload key
 
 ### Upload to Play Console
 
 1. Go to Google Play Console
 2. Create new app or select existing
 3. Navigate to Release → Production
 4. Upload your signed AAB file
 5. Complete all required store listing fields
 6. Submit for review
 
 ### After Submission
 
 - [ ] Monitor Play Console for review status
 - [ ] Respond promptly to any reviewer questions
 - [ ] Monitor crash reports and ANR data
 - [ ] Prepare marketing materials
 - [ ] Plan launch announcement
